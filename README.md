# SimpleDualSheath

Sheaths left-hand weapons/shields on dedicated left/back nodes, manages
scabbard (`Scb`/`ScbLeft`) visibility, optionally puts shields on backs and
auto-equips NPC left hands.

## Versions

* `SimpleDualSheath/` — legacy Visual Studio / `sse-build-resources` project
  (SE 1.5.x / AE 1.6.x, unmaintained).
* `src/` + `CMakeLists.txt` — **maintained port** on
  [`CommonLibSSE-NG`](https://github.com/alandtse/CommonLibSSE-NG) v12.1.0
  (`lib/commonlibsse-ng` submodule), built for **SE/AE from one DLL**,
  including Skyrim **1.7.99+** support. Version **1.6.0**.

## 1.7 compatibility notes

* `SKSEPlugin_Version` is generated by CommonLib with
  `AddressLibraryPostAE` + `AddressLibraryV5`, so the SKSE 2.3.1 pre-load gate
  (`must be recompiled for new address library`) passes on 1.7.99+.
  Format-5 address libraries (`versionlib-1-7-*.bin`) load natively.
* All hook sites (engine function IDs + in-function offsets) were verified
  byte-for-byte or shape-for-shape against `SkyrimSE.exe` **1.7.104.0**:
  `scbDetach`, shield-hide and `RemoveWeaponScabbard` sites are identical to
  1.6; the `15746` attach-function sites keep the same frame layout
  (`[rbp+0x77]` biped, `[rbp+0x5F]` root, `r15d` slot) and branch geometry.
  Startup byte-validation (`EngineExtensions::ValidateMemory`, same patterns
  as the legacy build) aborts loading if any site drifts on a future game
  version instead of crashing.
* Two residual risks on future 1.7.x point releases (documented in
  `src/EngineExtensions.h`): the `WeapTypeToNode` array-init iteration mapping
  (cosmetic worst case) and the shield-hand-workaround actor recovery
  (config-gated, off by default).

## Build

### Windows (Visual Studio 2022)

Requires: [Visual Studio 2022](https://visualstudio.microsoft.com/) (Desktop
development with C++), [CMake](https://cmake.org/download/) ≥ 3.21,
[Ninja](https://ninja-build.org/) and a [vcpkg](https://vcpkg.io/) checkout
with `VCPKG_ROOT` set:

```powershell
git submodule update --init lib/commonlibsse-ng
cmake --preset release
cmake --build build/release
```

This uses the `vcpkg.json` manifest (`spdlog`, `fmt`, `xbyak`) with the
`x64-windows-static-md` triplet and builds SE+AE into one DLL.
Output: `build/release/SimpleDualSheath.dll`.

### macOS (LLVM cross-compile, verified)

Requires: `brew install llvm cmake ninja xwin`, plus a provisioned Windows
SDK/CRT sysroot (via `xwin splat`) and a `vcpkg` cross-install. See
`docs/06_CROSS_COMPILING_SKSE_PLUGINS_WITH_LLVM.md` for the full pipeline;
with the workspace sysroot in place the build is:

```bash
git submodule update --init lib/commonlibsse-ng
cmake -B build -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=/Volumes/S512/Projects/ETC/winsdk/toolchain/clang-cl-msvc.cmake \
  "-DCMAKE_PREFIX_PATH=/Volumes/S512/Projects/ETC/vcpkg/installed/x64-windows-cross" \
  -DCMAKE_BUILD_TYPE=Release \
  -DENABLE_SKYRIM_SE=ON -DENABLE_SKYRIM_AE=ON -DENABLE_SKYRIM_VR=OFF
cmake --build build
```

Output: `build/SimpleDualSheath.dll` (PE32+, exports `SKSEPlugin_Load`,
`SKSEPlugin_Version`, `SKMP_GetPluginInterface`). The root `vcpkg.json` is
only used by the Windows/vcpkg-toolchain flow; the cross build consumes the
prebuilt `x64-windows-cross` overlay instead.

## Install

Build a release archive with `scripts/package-release.sh` (or on Windows zip
`build/release/SimpleDualSheath.dll` with `dist/SimpleDualSheath.ini` in the
same layout). Install the resulting `dist/SimpleDualSheath v1.6.0.zip` with
any mod manager (MO2 / Vortex / manual extract into `Data/`):

* `SimpleDualSheath.dll` → `Data/SKSE/Plugins/`
* `dist/SimpleDualSheath.ini` → `Data/SKSE/Plugins/` (all keys optional;
  defaults to swords/axes/maces/daggers/staves on Player+NPC)

## Required mods

* [SKSE](http://skse.silverlock.org) — version matching your game:
  2.0.20 for SE 1.5.97, 2.1.x–2.2.x for AE 1.6.x, **2.3.1 for 1.7.99+**.
* [Address Library for SKSE Plugins](https://www.nexusmods.com/skyrimspecialedition/mods/32444)
  (all-in-one) — provides the `version-*.bin` / `versionlib-*.bin` database
  for your exact game version in `Data/SKSE/Plugins/` (including
  `versionlib-1-7-104-0.bin` for 1.7.104).
* A skeleton with left-side sheath nodes (e.g.
  [XP32 Maximum Skeleton Special Extended](https://www.nexusmods.com/skyrimspecialedition/mods/1988))
  — provides `WeaponSwordLeft`, `ShieldBack`, `ScbLeft`, etc. Without these
  nodes the plugin loads but has nothing to attach to and falls back to
  default placement.
